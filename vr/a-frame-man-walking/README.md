# Homens a caminhar ao acaso

Três modelos CesiumMan caminham ao acaso pela floresta. A animação de caminhar vem dentro do modelo
e é corrida pelo componente `animation-mixer` (aframe-extras); o percurso é feito pelo componente
`walking`, em `scripts.js`.

Modelo: <a href="https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CesiumMan">CesiumMan</a>
(exemplos glTF da Khronos, CC BY 4.0, Cesium).

Feito com <a href="https://aframe.io/docs/1.6.0/">A-Frame v1.6.0</a>.
