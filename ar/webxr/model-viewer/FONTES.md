# Origem

Migrado do projeto Glitch `rumbling-hulking-flute` (backup de 2025-12-24), que é uma adaptação do exemplo
[Model Viewer](https://aframe.io/aframe/examples/showcase/model-viewer/) do A-Frame (licença MIT, ver LICENSE.md).

| Ficheiro | Origem |
|---|---|
| *.js, message.html | ficheiros do projeto Glitch |
| shadow.png | exemplo oficial do A-Frame (o original estava no CDN do Glitch, que deixou de funcionar) |
| modelo do triceratops | https://cdn.aframe.io/examples/ar/models/triceratops/scene.gltf (o original estava no 000webhost, que deixou de funcionar) |

O modo AR usa WebXR: funciona no Chrome para Android com ARCore. No computador, o modelo roda com o rato.
