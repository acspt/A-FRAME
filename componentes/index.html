Componentes do A-Frame Registry

Um exemplo a funcionar para cada um dos 42 componentes listados em aframe.io/aframe-registry. Voltar aos exemplos

Muitos destes componentes são antigos: cada exemplo usa a versão do A-Frame com que o componente funciona (indicada em cada cartão). Abrir através de um servidor (por exemplo Live Server), não diretamente do disco.

Funcionam no computador

Alongpath Uma entidade segue um caminho (curva) definido por pontos. A caixa vermelha percorre a curva azul em ciclo. A-Frame 1.0.4 Animation Animações com anime.js (componente original, que depois passou a fazer parte do A-Frame). O cilindro sobe e desce, a caixa muda de cor e as esferas giram à volta. A-Frame 0.8.2 Audioanalyser Analisa o som (Web Audio) e deteta batidas, volume e frequências. Clica na esfera para tocar a música: a esfera pulsa a cada batida detetada. A-Frame 1.8.0 Crawling Cursor O cursor desliza pela superfície dos objetos em vez de ficar a uma distância fixa. Arrasta o rato para olhar: o anel azul cola-se à superfície dos objetos. A-Frame 0.7.0 Environment Cria ambientes completos (céu, chão, árvores, luz) com uma só linha. Floresta pronta a usar. Muda o preset (forest, egypt, tron, japan, dream...) para outro ambiente. A-Frame 1.8.0 Event Set Muda propriedades de uma entidade quando acontece um evento (clique, rato por cima...). Passa o rato por cima da caixa (muda de cor) e clica (aparecem os olhos). A-Frame 1.8.0 Extras: Animation Mixer Toca as animações que vêm dentro de modelos glTF. O CesiumMan caminha usando a animação guardada no ficheiro .glb. A-Frame 1.8.0 Extras: Grid Chão em grelha quadriculada, útil para testar cenas. Uma grelha no chão com alguns objetos por cima. A-Frame 1.8.0 Extras: Json Model Carrega modelos no formato JSON antigo do three.js (THREE.JSONLoader). Um flamingo em formato JSON do three.js a rodar. Formato antigo: só funciona com A-Frame até 0.8. A-Frame 0.8.2 Extras: Object Model Carrega cenas no formato JSON do three.js (THREE.ObjectLoader). Uma cena exportada com object.toJSON() do three.js (um nó e uma caixa). A-Frame 1.8.0 Extras: Ocean Oceano animado com ondas, em estilo low poly. Um mar azul com ondas a mexer. A-Frame 1.8.0 Extras: Tube Tubo que segue um caminho definido por pontos. Um tubo laranja em forma de curva. A-Frame 1.8.0 Forcegraph Grafo 3D de nós e ligações, a partir de um ficheiro JSON. Rede de personagens de "Os Miseráveis". Usa WASD para voar e passa o rato pelos nós para ver o nome. A-Frame 1.8.0 Layout Organiza as entidades filhas em linha, círculo, grelha, cubo, pirâmide... Oito caixas em círculo a rodar e uma fila de esferas em linha. A-Frame 1.8.0 Lerp Suaviza as mudanças de posição, rotação e escala (interpolação linear). As duas caixas saltam de posição a cada segundo: a de cima muda de repente, a de baixo (com lerp) desliza. A-Frame 0.6.0 Line Desenha linhas entre dois pontos. Três linhas coloridas. (Mais tarde o componente line passou a fazer parte do A-Frame.) A-Frame 0.5.0 Log Mostra mensagens de consola (console.log) dentro da cena VR. O painel mostra as mensagens enviadas com o evento log ao clicar nas caixas. A-Frame 1.8.0 Metronome Emite eventos ao ritmo de uma música (batidas por minuto), para cenas musicais. A esfera pulsa a cada batida (beat) do metrónomo, a 100 batidas por minuto. A-Frame 1.8.0 Mountain Montanha gerada aleatoriamente a partir de um mapa de alturas. Uma montanha diferente cada vez que se abre a página. A-Frame 0.3.0 Outline Efeito de contorno (linha à volta) em todos os objetos da cena. Os objetos aparecem com contorno preto, estilo desenho animado. A-Frame 0.7.1 Particle System Sistemas de partículas: neve, chuva, pó, estrelas. Neve a cair sobre a cena. Muda o preset para rain, dust ou default. A-Frame 1.0.4 Physics System Física (gravidade e colisões) com o motor Cannon.js. As caixas caem com a gravidade e chocam com o chão. A-Frame 1.0.4 Point Desenha pontos (com tamanho fixo no ecrã ou com perspetiva). Pontos coloridos a várias distâncias. A-Frame 1.0.4 Rain Chuva a cair à volta da câmara. Chuva sobre uma cena simples. A-Frame 0.7.1 Raytrace Superfícies desenhadas com raytracing num shader GLSL. A caixa mostra uma bolha 3D calculada no shader (como uma janela para outro mundo). A-Frame 1.8.0 Room Cria salas com paredes, chão, teto e portas, e liga as salas com corredores. Duas salas ligadas por um corredor. Usa WASD e o rato para entrar. A-Frame 1.2.0 Slice9 Imagem "9-slice": os cantos mantêm o tamanho e o centro estica (ótimo para painéis e balões). Um balão de texto feito com uma imagem pequena esticada sem deformar os cantos. A-Frame 1.3.0 Spritesheet Anima uma imagem spritesheet (várias imagens numa só grelha). O porco caminha: a animação muda o progress de 0 a 1 e o componente mostra cada imagem da grelha. A-Frame 1.8.0 Stats In VR Mostra as estatísticas de desempenho (FPS) dentro da cena, também em modo VR. O painel de estatísticas aparece à frente da câmara, mesmo em VR. A-Frame 0.5.0 Super Hands Interação natural com as mãos/comandos: agarrar, esticar, arrastar e largar. Com o rato: carrega numa caixa e arrasta para a mover. Em VR, agarra com o gatilho dos comandos. A-Frame 1.4.2 Text Geometry Texto 3D com volume (geometria), em vez de texto plano. O texto "Ola, A-Frame!" em 3D a rodar. A-Frame 1.4.1

Precisam de hardware próprio

Abrem no computador, mas só se vê o efeito com o equipamento indicado.

Auto Detect Controllers Deteta automaticamente o tipo de comando VR ligado (Vive, Oculus, Daydream, GearVR). Abre num óculos VR com comandos: os comandos aparecem nas mãos. No computador vê-se só a cena. Precisa de: comandos VR. A-Frame 0.5.0 Controller Cursor Cursor (raio) que sai de um comando VR com tracking, para apontar e clicar. Com um comando Vive, aponta para a esfera e carrega no gatilho. No computador não há comando. Precisa de: comando Vive. A-Frame 0.5.0 Gaze Control Controla o olhar da câmara com os olhos (eye tracking pela webcam, com WebGazer). Dá permissão à webcam e olha para os lados do ecrã: a câmara roda para onde olhas. Funciona melhor depois de clicar em vários pontos do ecrã a olhar para o rato (calibração). Precisa de: webcam. A-Frame 1.0.4 GearVR Controls Suporte para o comando do Samsung GearVR. Só funciona no GearVR (Samsung + óculos). No computador vê-se a cena sem comando. Precisa de: GearVR. A-Frame 0.5.0 Leap Hands Mãos virtuais com o sensor Leap Motion. Precisa de um sensor Leap Motion ligado ao computador (com o software Leap). Sem sensor vê-se só a cena. Precisa de: Leap Motion. A-Frame 0.8.2 Motion Capture Grava e reproduz movimentos da cabeça e dos comandos VR. Reproduz uma gravação de movimentos de comandos VR (as mãos movem-se sozinhas). Carrega em espaço para gravar com comandos VR ligados. Precisa de: comandos VR (para gravar). A-Frame 0.7.0 Shake2show Abanar o telemóvel mostra ou esconde um objeto (por exemplo um menu). No telemóvel, abana-o para mostrar ou esconder o smile amarelo à frente da câmara. Precisa de: telemóvel. A-Frame 0.7.0 Speech Command Comandos de voz (Chrome) para mudar atributos de entidades. Diz "vermelho", "azul" ou "esconder"/"mostrar" (em inglês funciona melhor). Sem microfone, usa as teclas R, B, H e S. Precisa de: microfone (Chrome). A-Frame 0.4.0 Stereo Mostra entidades só num dos olhos em VR (para imagens e vídeos 3D estereoscópicos). Em VR, a caixa vermelha só aparece no olho esquerdo e a azul só no direito. No computador vê-se como o olho esquerdo. Precisa de: óculos VR. A-Frame 1.4.2 Teleport Controls Teletransporte em VR: aponta com o comando para o chão e salta para lá. Com comandos Vive/Oculus: carrega no touchpad/joystick, aponta para o chão e larga para te teletransportares. Precisa de: comandos VR. A-Frame 0.8.2 UI Widgets Botões, interruptores, botões rotativos e sliders para usar com os comandos VR. Os widgets ficam sobre uma mesa. Em VR, toca-lhes com as mãos (hand-controls) para os usar. Precisa de: comandos VR. A-Frame 0.5.0 (incluído no componente)
