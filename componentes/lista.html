Componentes do A-Frame Registry

Um exemplo a funcionar para cada um dos 42 componentes listados em aframe.io/aframe-registry. Voltar aos exemplos

Muitos destes componentes são antigos: cada exemplo usa a versão do A-Frame com que o componente funciona (indicada em cada cartão). Cada componente tem duas versões: a primeira (v0) é o exemplo do README do componente (com os ajustes mínimos para funcionar) e a segunda (v1) é um exemplo mais completo, pensado para se ver o efeito. Abrir através de um servidor (por exemplo Live Server), não diretamente do disco.
